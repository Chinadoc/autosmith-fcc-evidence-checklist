# Same FCC ID. Is it the same replacement key?

An FCC ID gives you a place to begin researching radio equipment. It does not answer every question involved in replacing an automotive key. A useful workshop record keeps the identifier, the candidate part and the vehicle application separate.

This article and free browser worksheet are from **AutoSmith Pro**, an automotive locksmith operations product. The worksheet runs locally in your browser, without an account or a data upload. It does not provide a compatibility verdict or programming instructions.

## Start with the question you are trying to answer

“What equipment does this label identify?” and “Which part should I order for this vehicle?” are different questions. The FCC's equipment-label rule describes an FCC identifier on authorized equipment. It does not prescribe a replacement part for your customer's vehicle. [47 CFR § 2.925](https://www.ecfr.gov/current/title-47/section-2.925)

Record the full text following “FCC ID,” rather than substituting a serial number. Follow the manufacturer's instructions when inspecting a user-accessible cover. A photograph helps you revisit an ambiguous character without relying on memory. AutoSmith's [public FCC guide](https://autosmithpro.com/fcc/?utm_source=github&utm_medium=resource&utm_campaign=fcc_evidence_20261021) explains the identifier and its lookup limits.

## Give each piece of evidence a job

Use separate lines for the vehicle context, the part reference, the physical comparison and the source supporting each observation. A supplier listing is useful as a candidate; preserve the listing's actual wording and applicable market or year instead of extending it to other variants.

Our suggested worksheet has three possible outcomes:

- **Research lead:** an identifier is available, but the supporting checks are incomplete.
- **Evidence recorded:** the checks have been recorded for a technician to review. This still is not a fitment verdict.
- **Review conflict:** two observations disagree. Keep both visible and identify what would resolve the difference.

Before ordering, write down the unresolved question. For example: “The housing looks similar; which exact part reference and vehicle application connect this candidate to this job?” That is a more useful handoff than an unsupported “matches.”

## Keep the record small and practical

The worksheet deliberately has no VIN, customer name or contact field. Use your approved job system for that information. This public training resource needs only an equipment identifier, source references and non-sensitive notes.

The included fictional scenarios teach how to notice missing evidence. They are not observations of real vehicles, FCC filings, supplier inventory, conversion rates or customer jobs. No fitment, start authorization or tool capability should be inferred from them.

Open the [live browser worksheet](https://chinadoc.github.io/autosmith-fcc-evidence-checklist/) or download this repository and open `index.html` in any modern browser. You can copy a Markdown note or print the worksheet. The form does not persist after reloading; save the note deliberately if you need it. Its links go to public sources, and the AutoSmith link carries a referral tag so aggregate visits from this resource can be distinguished.
