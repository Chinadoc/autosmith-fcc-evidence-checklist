# Replacement-key research worksheet

Educational worksheet from AutoSmith Pro. This is not a fitment or programming verdict.

1. Copy the FCC ID exactly as printed; keep serial and part references separate.
2. Record the source URL and date. Note which claim the source actually supports.
3. Check the exact vehicle application and market against appropriate part information.
4. Compare the actual candidate's relevant physical and recorded details.
5. Preserve conflicting observations. Name the next check rather than guessing.
6. Verify tool support and service prerequisites separately before promising a job.
